# Voxly AI – Smart Desktop Assistant

**Talk. Ask. Get things done.**

Voxly AI is an AI-powered desktop assistant designed to make computer usage easier through voice and text commands.

## Features

- 🎙️ Voice-based interaction
- 💬 Text-based commands
- 🧠 AI-powered command understanding
- 💻 Open desktop applications
- ⚡ Perform supported computer tasks
- 🌐 Tamil, English and Tanglish support *(if implemented)*
- 🔒 Confirmation for sensitive actions

## How It Works

1. Give Voxly AI a voice or text command.
2. Voxly understands your request.
3. It identifies the required application or action.
4. It performs the supported task.
5. It provides a response.

## Example Commands

- "Open Chrome"
- "Open Notepad"
- "Search for Python tutorials"
- "Open my project folder"
